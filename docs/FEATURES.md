# Features

## Current Features

### 1. Text Generation
- Support for OpenAI GPT, Claude, and Gemini
- Customizable prompt and token limits
- Real-time response display

### 2. Image Generation
- Generate images from text descriptions
- Support for DALL-E and Stability AI
- Customizable image sizes

### 3. Service Status
- Real-time API availability check
- Visual indicators for connected services
- Configuration validation
