# To-Do List Application - Usage Guide

## Getting Started

### Opening the Application
1. Open the `index.html` file in your web browser
2. No installation or internet connection required
3. The application will load with your previously saved tasks

## Adding Tasks

### Method 1: Using the Add Button
1. Type your task in the input field
2. Click the "+" button
3. Task appears in your list

### Method 2: Using Keyboard
1. Type your task in the input field
2. Press **Enter** key
3. Task is added automatically

**Tips:**
- Keep task descriptions concise and clear
- Maximum 200 characters per task
- You can add multiple tasks at once

## Managing Tasks

### Completing a Task
1. Click the checkbox next to a task
2. Task text will have a strikethrough effect
3. Completed count increases
4. Progress bar updates

### Uncompleting a Task
1. Click the checkbox again to uncheck it
2. Strikethrough effect is removed
3. Task returns to active status

### Editing a Task
1. Hover over a task to reveal the edit button (pencil icon)
2. Click the edit button
3. A dialog appears with the current task text
4. Edit the text and confirm
5. Changes are saved automatically

### Deleting a Task
1. Click the trash icon on the right side of a task
2. A confirmation dialog appears
3. Click "OK" to confirm deletion
4. Task is permanently removed

## Filtering Tasks

### View All Tasks
- Click the **"All"** button
- Shows all tasks (completed and active)
- This is the default view

### View Active Tasks
- Click the **"Active"** button
- Shows only incomplete tasks
- Useful for focusing on what needs to be done

### View Completed Tasks
- Click the **"Completed"** button
- Shows only finished tasks
- Great for reviewing your accomplishments

## Task Statistics

The dashboard displays three key statistics:

**Total Tasks**
- Shows the total number of all tasks
- Includes both active and completed tasks

**Active**
- Shows the number of incomplete tasks
- Tasks that still need to be done

**Completed**
- Shows the number of finished tasks
- Your accomplishments

## Progress Tracking

### Progress Bar
- Visual indicator showing completion percentage
- Fills up as you complete more tasks
- Ranges from 0% to 100%

### Progress Text
- Displays the exact completion percentage
- Updated automatically when tasks change

## Clearing Tasks

### Clear Completed Tasks
1. Click the **"Clear Completed"** button (trash icon with text)
2. A confirmation appears showing how many tasks will be deleted
3. Click "OK" to confirm
4. All completed tasks are removed
5. Active tasks remain unchanged

**Note:** This action cannot be undone, but you can add tasks again if needed.

## Data Persistence

### Automatic Saving
- All changes are saved automatically
- Data is stored in your browser's local storage
- No internet connection needed
- No account required

### Data Persistence
- Tasks are saved even after closing the browser
- Close and reopen the tab - your tasks are still there
- Restart your computer - your tasks persist
- Switching browsers may not show your tasks (data is browser-specific)

### Clearing Data
- **Important:** Clearing your browser's cache/history will delete your tasks
- To backup your tasks, take a screenshot or write them down

## Tips & Tricks

### ✨ For Productivity
1. **Keep it simple** - Use clear, specific task descriptions
2. **Break it down** - Split large tasks into smaller ones
3. **Prioritize** - Focus on completing important tasks first
4. **Review regularly** - Check your progress daily
5. **Celebrate wins** - Take time to appreciate completed tasks

### 🎯 Best Practices
1. **Be specific** - Instead of "Work", use "Complete project proposal"
2. **Use action verbs** - Start with verbs like "Complete", "Review", "Call"
3. **Avoid duplicates** - Check if a similar task exists before adding
4. **Set reasonable goals** - Add tasks you can realistically complete
5. **Review and clean up** - Regularly clear completed tasks

### 💡 Pro Tips
1. Use time-based descriptions: "Morning: Answer emails", "Afternoon: Team meeting"
2. Include deadlines in task text: "Finish report (Friday)"
3. Add priority indicators: "[HIGH] Fix bug", "[LOW] Update documentation"
4. Use categories: "Work: ...", "Personal: ...", "Shopping: ..."
5. Break large projects into actionable steps

## Troubleshooting

### Tasks Disappeared
**Problem:** All your tasks are gone
**Solutions:**
- Check if you're using a different browser
- Check if you cleared your browser cache/data
- Try refreshing the page
- Tasks are stored locally per browser

### Input Field Not Working
**Problem:** Can't type in the task input field
**Solutions:**
- Click on the input field to focus it
- Try refreshing the page
- Check if JavaScript is enabled in your browser

### Changes Not Saving
**Problem:** Tasks aren't being saved
**Solutions:**
- Check if local storage is enabled
- Ensure you're not in private/incognito mode (data may not persist)
- Check browser storage quota
- Try a different browser

### Buttons Not Responding
**Problem:** Buttons don't seem to work
**Solutions:**
- Refresh the page
- Clear browser cache
- Try a different browser
- Check browser console for errors

## Browser Compatibility

The application works best on:
- ✅ Chrome/Chromium (latest)
- ✅ Firefox (latest)
- ✅ Safari (latest)
- ✅ Edge (latest)
- ✅ Mobile browsers (iOS Safari, Chrome Mobile, Firefox Mobile)

**Note:** Local storage requires a modern browser with JavaScript enabled.

## Storage Information

**Storage Capacity:**
- Most browsers: 5-10 MB
- That's enough for thousands of tasks

**Storage Location:**
- Browser local storage (not cloud)
- Device-specific storage
- Not shared between browsers

**Data Format:**
- JSON format
- Each task contains: ID, text, completion status, creation date
